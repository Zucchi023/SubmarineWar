# [潜水艦あてゲーム](https://zucchi023.github.io/SubmarineWar/)

6×6 のグリッドに隠れた 4 隻の潜水艦（2・3・4・5 マス）の配置を推理し合う、ブラウザで遊べる CPU 対戦ゲームです。

## あそびかた

1. **配置**：2・3・4・5 マスの船を 1 隻ずつドラッグして置きます。船同士は上下左右に接してはいけません（斜めは OK）。
2. **攻撃**：「質問」ツールで相手の盤面のマスを選ぶと、そこにある船の長さ（なければハズレ）がわかります。当たったら続けて質問でき、外れたら相手の番です。予想盤面には 2〜5・× を書き込んでメモできます。
3. **判定**：自分の番に「わかった！」と宣言すると答え合わせ。相手の配置をすべて正確に当てていれば勝ち、間違っていれば負けです。

CPU の強さは タイトル画面で「弱い / 普通 / 強い」から選べます。

## 動かし方

`index.html` をブラウザで開くだけで遊べます（サーバー不要）。
